# Superstore Excel KPI Dashboard

An interactive Excel dashboard built on the Kaggle Superstore dataset.

## Tools
- Python (pandas, openpyxl, win32com)
- Microsoft Excel (pivot tables, slicers, charts)

## Features
- KPI cards: Total Sales, Total Profit, Total Orders, Average Discount
- Sales by Region bar chart
- Top 10 Products by Sales bar chart
- Monthly Sales Trend line chart
- Interactive slicers for Region and Category

## Key Findings
- **Total performance:** $2.30M in sales, $286K in profit, 5,009 orders, 15.6% average discount.
- **West region leads in total sales ($725K)**, ahead of East ($679K), Central ($501K), and South ($392K).
- **Canon imageCLASS 2200 Advanced Copier is the top product ($61.6K)** in total sales.
- Sales trend upward year-over-year from 2014 to 2017.
